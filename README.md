# Clipboard-History
一、这是什么
----------------------------------------
一个只保存在本机的剪贴板历史工具：自动记录你复制的文字和图片，随时打开查找、置顶或删除，点一下就能再次复制使用。

· 版本：1.0.0

· 完整性校验：参见文件夹内的 SHA256.txt。


二、主要功能
----------------------------------------
1. 搜索筛选：

· 点击窗口左上角搜索图标，输入框从右侧展开。

· 输入关键词实时筛选，搜索时图片隐藏。

· 按 Ctrl+F 可直接展开并聚焦搜索。


2. 点击卡片再次复制：

· 点击任意卡片，即把内容复制回剪贴板，底部提示「已复制」。

· 该卡片会移到最前面，再到需要的地方按 Ctrl+V。


3. 置顶 / 取消置顶：

· 鼠标移到卡片上，右侧出现图钉和垃圾桶按钮。

· 点图钉可置顶 / 取消置顶；置顶内容固定在顶部，并且永久保留，不参与自动清理。


4. 删除记录：

· 普通记录点垃圾桶直接删除。

· 置顶记录删除前会弹出确认框，防止误删。


5. 设置：

· 点击右上角滑块图标进入设置。

· 保存天数：可选 3 / 5 / 7 天，或自定义 1–30 天，到期自动清理旧记录。缩短保存天数且存在过期记录时，会先提示将清理多少条。

· 开机自动启动：默认关闭。

· 清空历史：清空所有未置顶记录，置顶内容保留，操作前会确认。

· 打开数据文件夹：查看本机历史数据。


三、启动与关闭
----------------------------------------
1. 启动方式：

双击文件夹里的「历史剪贴板.exe」或双击带图标的快捷方式「历史剪贴板」。

2. 托盘常驻：

· 启动后程序常驻在任务栏右下角托盘区，图标可能收在「^」里。

· 点击托盘图标可以打开 / 收起窗口。

· 右键托盘图标可打开或退出。

3. 关闭窗口：

关闭窗口只是隐藏到托盘，程序仍在后台记录。

4. 完全退出：

右键托盘图标 →「退出」即可完全退出，关闭窗口不会退出。


四、自动记录规则
----------------------------------------
1. 自动记录复制的文字和图片；在资源管理器里复制「文件」不会被记录。

2. 相同内容重复复制不会生成新卡片，而是把原卡片更新时间并排到最前面，包括点击卡片再次复制。

3. 判断“相同内容”时：

· 文字忽略换行符与首尾空白的差异；

· 图片按画面内容判断，同一张图不会重复记录。

4. 启动软件时，剪贴板里已有的内容不会被记录。

5. 已知限制：

· 非常快地连续复制（间隔不到约 1 秒）可能漏记；

· 密码输入框等受保护的软件可能阻止记录。


五、数据备份与迁移
----------------------------------------
1. 所有数据只保存在本机，程序不联网、不上传。

2. 数据文件夹就在程序旁边，即 data 文件夹，包含历史索引、图片和设置。

3. 迁移到别的电脑或位置：把整个「历史剪贴板」文件夹复制过去即可。

4. 移动程序文件夹后：直接双击「历史剪贴板.exe」，文件夹内的快捷方式可能因路径变化失效，可重新创建。


六、常见问题
----------------------------------------
1. Windows 提示「智能应用控制」或 SmartScreen

本程序未做数字签名，为兼容 Windows 11 的应用控制，程序 exe 保留了官方 Electron 的原始文件哈希，正常应能启动。若仍被拦截，请先核对 SHA256.txt，再决定是否继续。

2. 杀毒软件提示

可先核对 SHA256.txt 与文件是否一致，再进行常规扫描。

3. exe 图标是 Electron 默认图标？

是的，为通过系统信任校验，exe 本体不能改写图标；文件夹内提供了带应用图标的快捷方式，请优先使用它启动。

4. 有些内容没有被记录

可能是复制间隔太短、剪贴板内容没有变化，或来源软件限制了记录。

5. 数据文件夹无法写入

请把程序放在普通文件夹中（不要放在 Program Files、OneDrive 或只读位置）。

6. 程序打开后没有窗口

请检查任务栏右下角的托盘区（可能在「^」中），点击图标打开。
