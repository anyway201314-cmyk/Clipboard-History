# 06 · 打包发布与使用说明

> 文档状态：v1.0（阶段 6 定稿）
> 最后更新：2026-11-19
> 说明：本文记录发布流程与交付实测信息；面向用户的最终使用说明以 `docs/使用说明.txt` 为准（组装时复制到交付目录）。

## 1. 交付目标

- 形式：免安装绿色版文件夹，双击 exe 即可运行。
- 数据：与程序同目录的 `data/` 文件夹，整体拷贝即可迁移。
- 不含：安装器、自动更新、联网功能。

## 2. 交付结构

```
交付/历史剪贴板-v1.0.0/
├── 历史剪贴板.exe        # 保留官方 Electron 原始二进制哈希
├── 历史剪贴板.lnk        # 带应用图标的快捷方式（指向当前目录）
├── 历史剪贴板.ico        # 快捷方式图标
├── resources/            # electron-builder 生成（含 app.asar）
├── locales/ 等运行时文件  # 由 electron-builder 生成
├── 使用说明.txt          # UTF-8（带 BOM）、CRLF
└── SHA256.txt
```

检查项（已实测）：

- 不含 `data/`、`data-dev/`、源码、docs、开发日志、测试数据。
- `使用说明.txt` 为 UTF-8（带 BOM/CRLF），记事本可直接打开。
- 版本信息（1.0.0）与设置页显示一致。
- **exe 本体保留官方 Electron 二进制哈希**（见 3.1，智能应用控制兼容）；嵌入图标为 Electron 默认，交付文件夹内提供带应用图标的快捷方式。
- 窗口与托盘图标为应用自定义图标；托盘图标随系统主题明暗自动切换。
- 便携性：首次运行只在程序目录创建 `data/`；`%APPDATA%` / `%LOCALAPPDATA%` 无残留（单实例锁文件位于 `data/userData/lockfile`）。

## 3. 构建与发布步骤

1. 确认当前分支工作区干净，`node --test` 全部通过，版本号 1.0.0。
2. `npm run dist`（electron-builder `--win --dir`，随后自动执行 `scripts/restore-exe.js`）。
3. **核对 exe 哈希与官方一致**：
   `sha256sum node_modules/electron/dist/electron.exe dist/win-unpacked/历史剪贴板.exe`
4. `node scripts/assemble-release.js`：
   - 复制 `dist/win-unpacked/` 到 `交付/历史剪贴板-v1.0.0/`
   - 清除任何测试残留 `data/`
   - 复制应用图标并创建快捷方式
   - 复制 `docs/使用说明.txt`（自动加 BOM、CRLF）
   - 校验 exe 哈希与官方一致
   - 生成 `SHA256.txt`
5. Defender 手动扫描交付文件夹；记录结果。
6. 冒烟测试：全新数据目录启动、复制文字与截图、置顶/删除/搜索、托盘、退出、重启、移动文件夹；在开启智能应用控制的系统上确认不被拦截。
7. 更新本文与《05》验收记录、当日开发日志；git 提交；用户确认后打 `v1.0.0` tag。

### 3.1 为什么 exe 使用官方 Electron 原始二进制

本机实测（2026-11-19）：Windows 11 智能应用控制开启时，electron-builder 修改过的未签名 exe 因哈希未知会被直接拦截；而官方 `electron.exe` 的哈希具有系统信誉，可以运行。因此构建后自动用官方二进制覆盖产物 exe（仅改文件名），保证交付物可启动。副作用是 exe 嵌入图标/版本为 Electron 默认，故使用窗口图标 + 快捷方式补足品牌体验，详见《02-技术方案》7.1。

## 4. 使用说明（面向用户）

> 最终交付版以 `docs/使用说明.txt` 为准（组装时写入交付目录）。本节内容与其保持同步。

### 4.1 启动与打开

1. 双击文件夹中的「历史剪贴板.lnk」（带应用图标）或「历史剪贴板.exe」。
2. 程序启动后会常驻在任务栏右下角的托盘区（可能需要点开「^」查看隐藏的图标）。
3. **点击托盘图标**即可打开历史窗口；再次点击可收起。
4. 移动整个文件夹后，快捷方式路径可能失效，此时直接双击 exe 即可（或在新的位置重新创建快捷方式）。

### 4.2 自动记录

- 你在电脑上复制的**文字**和**图片**会自动记录，无需任何操作。
- 复制文件不会被记录。
- 重复复制相同内容不会产生多条，只会更新时间并排到最前面。
- 说明：连续极快复制（间隔不到 1 秒）可能漏记；密码输入框等安全软件限制的内容无法记录。

### 4.3 查找与再次使用

- 打开窗口后，最新的记录在最上面。
- 左上角搜索图标：点击展开输入框，输入关键词即搜索文字内容；点 ✕ 清空；Esc 收起/隐藏窗口；Ctrl+F 展开搜索。
- **点击卡片**即可把内容复制回剪贴板，然后到需要的地方按 Ctrl+V 粘贴。
- 点击卡片右侧图钉可**置顶**；点击垃圾桶可**删除**（置顶内容删除前会确认）。
- 置顶内容永久保留，不会被自动清理。

### 4.4 设置

点击窗口右上角滑块图标：

- **保存天数**：3 / 5 / 7 天，或自定义 1–30 天；到期自动清理旧记录。
- **开机自动启动**：默认关闭；开启后开机自动在后台运行。
- **清空历史**：清空所有未置顶记录（置顶内容保留），操作前会确认。
- **打开数据文件夹**：查看本软件的数据（图片和历史索引）。

### 4.5 退出

- 关闭窗口只是隐藏到托盘，软件仍在后台记录。
- 如需完全退出：右键托盘图标 →「退出」。

### 4.6 数据与迁移

- 所有数据都保存在程序文件夹内的 `data` 文件夹中，不会上传网络。
- 换电脑或移动位置：把**整个「历史剪贴板」文件夹**复制过去即可，历史记录会一起带走。
- 建议定期把 `data` 文件夹复制一份作为备份。
- 移动文件夹后，开机自启路径会失效；手动启动一次软件即可自动更新。

### 4.7 常见问题

| 问题 | 说明 |
|---|---|
| 杀毒软件提示 | 本软件未做数字签名，可能出现提示。可核对 `SHA256.txt` 后再决定；不建议关闭系统防护。 |
| SmartScreen 提示 | 若出现，可点「更多信息」→「仍要运行」；请先确认文件来自你自己的这份交付文件夹。 |
| 智能应用控制拦截 | 交付 exe 使用官方 Electron 原始二进制（哈希与官方一致），正常情况下不会被拦截；若仍被拦截，请核对 SHA256 后联系开发者，不建议关闭系统防护。 |
| 数据文件夹无法写入 | 不要把程序放在 Program Files、OneDrive 或只读位置；移动到普通文件夹后重试。 |
| 记录不到内容 | 可能是极快连续复制、内容未变化、或来源软件限制了记录；详见「已知限制」。 |
| 占用空间变大 | 图片记录较多；可缩短保存天数，或在设置中清空历史。 |

## 5. 升级与迁移规则

- 小版本升级：保留原 `data/`，用新程序文件覆盖其余文件。
- 升级前建议复制一份 `data/` 备份。
- 数据结构（schemaVersion）变更必须提供迁移逻辑；程序只读取不高于自身支持版本的数据。
- 迁移后首次启动会做补清理与孤儿文件清理，属正常行为。
