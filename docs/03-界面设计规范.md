# 03 · 界面设计规范

> 文档状态：v0.2（浅色半透明主题修订）
> 最后更新：2026-11-19
> 适用：主窗口、设置页、弹窗文案、托盘图标

## 1. 设计原则

1. **简洁直观**：打开即用，一眼看懂；不增加学习成本。
2. **内容优先**：剪贴板内容与时间最重要，界面元素退居其次。
3. **轻盈半透明**：半透明白色表面 + Windows 11 亚克力背景，黑色文字保证可读性。
4. **反馈及时**：操作后 150ms 内给出视觉反馈（已复制、置顶、删除）。

## 2. 颜色（浅色半透明主题）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | `rgba(255, 255, 255, 0.45)` | 窗口内容背景（叠加在系统亚克力之上，保留下方可辨识的模糊轮廓） |
| `--bg-fallback` | `#F5F7FA` | 不支持亚克力时的窗口底色（系统层面） |
| `--bg-elevated` | `rgba(255, 255, 255, 0.52)` | 卡片、控件表面 |
| `--bg-hover` | `rgba(255, 255, 255, 0.72)` | 卡片/按钮悬停 |
| `--bg-active` | `rgba(255, 255, 255, 0.84)` | 按下态 |
| `--border` | `rgba(0, 0, 0, 0.10)` | 分隔线、描边 |
| `--accent` | `#1D4ED8` | 主强调、置顶标记、焦点环 |
| `--accent-hover` | `#1E40AF` | 强调悬停 |
| `--accent-soft` | `rgba(29, 78, 216, 0.12)` | 选中/高亮底色 |
| `--text` | `#111111` | 主文字（黑色） |
| `--text-secondary` | `#4A4A4A` | 时间、次要说明 |
| `--text-muted` | `#7C828B` | 占位符、禁用 |
| `--danger` | `#C62828` | 删除操作 |
| `--danger-soft` | `rgba(198, 40, 40, 0.10)` | 删除悬停底色 |
| `--success` | `#2E7D32` | 成功状态 |
| `--toast-bg` | `rgba(32, 33, 36, 0.92)` | 提示条底色（深色半透明） |
| `--toast-text` | `#FFFFFF` | 提示条文字 |

对比度要求：主文字与白色表面对比度 ≥ 7:1，次要文字 ≥ 4.5:1。置顶内容不能只靠颜色区分，必须有图标辅助（见卡片规范）。

## 3. 字体

```css
font-family: "Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif;
```

| 场景 | 字号/行高 | 字重 |
|---|---|---|
| 卡片正文/预览 | 13px / 1.5 | 400 |
| 时间、计数 | 11px / 1.3 | 400 |
| 搜索框 | 13px / 1.4 | 400 |
| 分区标题（置顶/结果） | 12px / 1.2 | 500 |
| 设置页标题 | 15px / 1.4 | 500 |
| 设置行标签 | 13px / 1.4 | 400 |
| 按钮文字 | 13px / 1.2 | 500 |

英文与数字使用同字体（Segoe UI 回退），不使用斜体。文字颜色统一为黑色系（`--text` / `--text-secondary`）。

## 4. 尺寸与间距

- 基础间距单位 **8px**；常用：4 / 8 / 12 / 16 / 24。
- 窗口：默认 **420×620**；最小 **360×500**；禁用最大化；初始高度不超过屏幕工作区（含任务栏之外区域）的 90%。
- 标题栏高度：48px；内容区左右内边距：12px。
- 卡片内边距：12px；卡片间距：8px；卡片圆角：10px。
- 按钮圆角：8px；搜索框圆角：8px；提示条圆角：8px。
- 滚动条：宽 6px；滑块 `rgba(0, 0, 0, 0.22)`，悬停 `rgba(0, 0, 0, 0.32)`，轨道透明；仅内容区出现。

## 5. 布局结构

```
┌────────────────────────────────────────────┐
│ [🔍]                         [×]           │ 收起状态：仅搜索图标 + 关闭
├────────────────────────────────────────────┤
│ [🔍] [ 搜索历史记录…          ✕ ]   [×]    │ 展开状态：图标 + 输入框 + 关闭
├────────────────────────────────────────────┤
│  📌 置顶                                    │ 分区标题（有置顶时显示）
│  ┌──────────────────────────────────────┐  │
│  │ 卡片（置顶）                          │  │
│  └──────────────────────────────────────┘  │
│  全部记录 / 搜索结果                        │ 分区标题
│  ┌──────────────────────────────────────┐  │
│  │ 卡片                                  │  │
│  ├──────────────────────────────────────┤  │
│  │ 卡片                                  │  │
│  └──────────────────────────────────────┘  │
│  …滚动自动加载更多                          │
└────────────────────────────────────────────┘
```

- 窗口使用 **Windows 11 亚克力（acrylic）** 系统背景，内容为半透明白色（`--bg`，不透明度 0.45），未展开搜索时也能透过窗口看到下方界面被模糊的轮廓；不支持亚克力时退化为 `--bg-fallback` 浅色背景。
- 标题栏整体为拖动区（`-webkit-app-region: drag`）；**搜索图标与设置图标之间的空白区域必须可拖动窗口**（`.search-wrap` 设为 `drag`，仅搜索图标、输入框、设置/关闭按钮等交互元素设 `no-drag`）。
- 搜索框默认收起，只显示左上角搜索图标；点击后输入框从图标右侧展开（180ms 过渡），关闭按钮始终在右侧。
- 列表为唯一滚动区域。
- 设置页为窗口内整页覆盖视图：顶部返回箭头 + 标题「设置」，底部显示版本号。

## 6. 组件规范

### 6.1 搜索（收起 / 展开）

**收起状态（默认）**

- 左上角仅显示 28×28 的搜索图标按钮，图标 15px，颜色 `--text-secondary`，悬停背景 `--bg-hover`。
- 标题栏右侧保留关闭按钮。
- 已激活搜索时不允许收起（避免隐藏正在生效的搜索条件）。

**展开行为**

- 点击搜索图标：输入框从图标右侧展开（`flex-grow` 0→1，180ms ease；透明度 140ms），并自动聚焦。
- 再次点击搜索图标：输入框为空则收起；有内容则只聚焦，不收起。
- 输入框失去焦点且为空：150ms 后自动收起。
- `Ctrl+F`：展开并聚焦（全选已有内容）。
- `Esc`：展开时若有内容 → 清空并保持展开；展开时为空 → 收起；收起时 → 隐藏窗口。
- 清空按钮（输入框右侧 ×）：清空内容并保持展开与焦点，立即恢复完整列表。

**输入框样式**

- 背景 `rgba(255, 255, 255, 0.58)`，1px `--border`，圆角 8px，高度 32px。
- 占位符「搜索历史记录…」，颜色 `--text-muted`。
- 聚焦：1px `--accent` 描边 + `--accent-soft` 外发光（不改变布局尺寸）。
- 输入防抖 200ms；中文输入法 composition 期间不触发搜索，结束后触发。

### 6.2 卡片

结构：内容区 + 元信息行。

- **卡片表面**：`--bg-elevated`、1px `rgba(0, 0, 0, 0.09)` 描边、圆角 10px，悬停 `--bg-hover`，按下 `--bg-active`。
- **文字内容**：最多 5 行，`white-space: pre-wrap`，`word-break: break-word`（长链接/长单词换行），超出以省略号截断（`-webkit-line-clamp: 5`）。正文颜色 `--text`。
- **图片内容**：缩略图最大宽度 100%，最大高度 120px，等比缩放（`object-fit: contain`），底衬 `rgba(0, 0, 0, 0.04)`，圆角 6px；加载中显示同尺寸占位。
- **元信息行**：高度 24px；左侧时间（11px，`--text-secondary`），右侧操作按钮（悬停或卡片获得焦点时显示）。
- **操作按钮**：置顶（图钉）、删除（垃圾桶），24×24，图标 15px；悬停背景 `rgba(0, 0, 0, 0.06)`；删除悬停背景 `--danger-soft`、图标 `--danger`；置顶激活时图标 `--accent`。
- **置顶标识**：卡片左侧 2px `--accent` 竖条 + 元信息行常显图钉图标（`--accent`），不依赖颜色单一维度。
- **键盘**：卡片可聚焦，焦点环 1px `--accent`；Enter / 空格触发复制。

### 6.3 分区标题

- 12px、500 字重、`--text-secondary`、字距 0.5px。
- 置顶分区带图钉图标（`--accent`，12px）。
- 无置顶时不显示置顶分区标题。
- 搜索时普通分区标题改为「搜索结果」。

### 6.4 空状态

- 居中显示：剪贴板线框图标（48px，`--text-muted`）。
- 文案：
  - 无记录：「还没有记录，复制点什么试试」
  - 搜索无结果：「没有找到相关内容」
- 文案 13px、`--text-secondary`；图标与文案间距 12px。

### 6.5 提示条（Toast）

- 位置：窗口底部居中，距底 16px。
- 规格：`--toast-bg`（深色半透明）背景、圆角 8px、内边距 8px 16px、12px 文字 `--toast-text`，轻阴影。
- 动画：淡入/淡出 150ms，显示 1.5s。
- 文案：「已复制」「复制失败，请重试」「已置顶」「已取消置顶」「已删除」等。
- 错误提示可在提示条末尾带 `--danger` 图标；技术细节只写日志。

### 6.6 顶部错误条

- 数据保存失败等严重问题时，在标题栏下方显示内联错误条：`--danger-soft` 背景、`--danger` 文字、左侧警告图标。
- 文案示例：「数据保存失败，请检查磁盘空间或文件夹权限」。

### 6.7 按钮与表单控件（设置页）

- 图标按钮：28×28，悬停 `--bg-hover`，焦点环 2px `--accent`。
- 文字按钮：无边框，13px；危险操作（清空历史）使用 `--danger`，悬停 `--danger-soft` 背景。
- 下拉框：浅色背景（`rgba(255, 255, 255, 0.70)`）、1px `--border`、圆角 8px、高度 32px；展开后选项悬停 `--bg-hover`。
- 数字输入框：同下拉框规格；范围 1–30，非法值阻止提交并显示提示。
- 开关：36×20，圆角 10px；关闭 `--border`，开启 `--accent`；滑块白色 16px；点击切换即时生效。
- 设置行：标签左对齐、控件右对齐；行高 48px；行间用 1px `--border` 分隔。

### 6.8 系统确认弹窗

使用 Electron 原生 `dialog.showMessageBox`（跟随系统浅色/深色主题），由主进程发起：

| 场景 | 标题 | 正文 | 按钮 |
|---|---|---|---|
| 删除置顶内容 | 删除置顶内容 | 这条内容已置顶，删除后无法恢复。确定删除吗？ | 取消 / 删除（默认取消） |
| 缩短保存天数 | 缩短保存天数 | 保存天数改为 N 天后，将清理 X 条过期记录（置顶内容不受影响）。 | 取消 / 继续（默认取消） |
| 清空历史 | 清空历史 | 将清空 X 条未置顶记录，置顶内容会保留。此操作无法撤销。 | 取消 / 清空（默认取消） |

危险按钮使用「删除」「清空」明确动词，不使用「确定」。

## 7. 时间显示规则

纯函数实现（`time.js`），每 30 秒刷新一次时间文本：

| 条件 | 显示 |
|---|---|
| 距今 < 60 秒 | 刚刚 |
| 距今 < 60 分钟 | N 分钟前 |
| 与当前同一天 | 今天 HH:mm |
| 与当前相差一天 | 昨天 HH:mm |
| 同一年 | M月D日 HH:mm |
| 其他 | YYYY年M月D日 HH:mm |

- 24 小时制，补零到两位分钟（如 09:05）。
- 使用本地时区；以 `createdAt` 为准。

## 8. 交互规则

| 操作 | 行为 |
|---|---|
| 点击搜索图标（收起态） | 展开输入框并聚焦 |
| 点击搜索图标（展开态、空） | 收起输入框 |
| 点击搜索图标（展开态、有内容） | 保持展开并聚焦，不收起 |
| 输入框失焦且为空 | 150ms 后自动收起 |
| 搜索框展开且为空按 Esc | 收起搜索框（不隐藏窗口） |
| 搜索框展开且有内容按 Esc | 清空搜索，保持展开 |
| 搜索框收起按 Esc | 隐藏窗口到托盘 |
| Ctrl+F | 展开并聚焦搜索框（全选） |
| 点击卡片内容区 | 复制回剪贴板；toast「已复制」；该卡片更新时间并移到最前（置顶内容移到置顶区最前） |
| 点击置顶按钮 | 切换置顶；即时生效；toast 反馈 |
| 点击删除按钮 | 非置顶直接删除；置顶弹系统确认框 |
| 搜索输入 | 200ms 防抖过滤；置顶区参与；图片隐藏；分页重置 |
| 滚动到底 | 自动加载下一页（每页 100 条），加载中显示小号 spinner |
| 点击托盘图标 | 显示/隐藏切换；显示时聚焦窗口 |
| 关闭按钮 / Alt+F4 | 隐藏到托盘（不退出） |
| 托盘菜单 | 打开窗口 / 退出 |

其他：

- 列表刷新时尽量保留滚动位置；置顶/删除导致条目移动属预期。
- 置顶按钮立即改变分区，不等待动画。
- 所有可交互元素提供键盘焦点可见样式（2px `--accent` 焦点环）。
- 图标按钮必须有中文 `aria-label` 与 `title`（如「置顶」「删除」「关闭」「搜索」）。

## 9. 图标与托盘

- 应用图标：圆角方形深蓝底（`#0B1E36`），白色剪贴板主体，`--accent` 高光线；提供 256/128/64/48/32/16 多尺寸 `.ico`。
- 托盘图标：提供**浅色版**与**深色版**两套（16×16、32×32）。根据系统任务栏明暗自动选择：任务栏深色用浅色图标，任务栏浅色用深色图标；系统主题切换时自动更新。
- 不使用文字徽标；不使用复杂渐变。

## 10. 可访问性与兼容

- 支持键盘 Tab 顺序：搜索图标 → （展开后）搜索输入框 → 清空按钮 → 关闭按钮 → 卡片操作按钮。
- 焦点状态不使用纯颜色区分（配合描边）。
- DPI 100% / 125% / 150% / 200% 下布局不溢出、文字不截断异常；窗口高度受屏幕工作区限制。
- 1366×768 等小屏可用（最小尺寸 360×500 保证列表可用）。
- 亚克力背景仅 Windows 11 支持；其他环境退化为浅色纯色背景，颜色按 `--bg-fallback`。

## 11. 中文文案规范

- 简洁、动词开头、使用中文标点；不使用感叹号堆叠。
- 统一用「记录」称呼历史条目；「置顶」「取消置顶」「删除」「搜索历史记录」。
- 错误提示说明「发生了什么」+「可以怎么办」，不暴露英文报错。
