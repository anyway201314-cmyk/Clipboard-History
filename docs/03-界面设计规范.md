# 03 · 界面设计规范

> 文档状态：草案（阶段 0 创建），阶段 3 前定稿
> 最后更新：2026-11-19
> 适用：主窗口、设置页、弹窗文案、托盘图标

## 1. 设计原则

1. **简洁直观**：打开即用，一眼看懂；不增加学习成本。
2. **内容优先**：剪贴板内容与时间最重要，界面元素退居其次。
3. **克制的深蓝**：深海军蓝背景 + 低饱和层次 + 单一点缀色，避免花哨渐变与重阴影。
4. **反馈及时**：操作后 150ms 内给出视觉反馈（已复制、置顶、删除）。

## 2. 颜色（深蓝主题）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#0B1E36` | 窗口背景 |
| `--bg-elevated` | `#12294A` | 卡片、设置面板 |
| `--bg-hover` | `#17335C` | 卡片/按钮悬停 |
| `--bg-active` | `#1B3A66` | 按下态 |
| `--border` | `#1E3A60` | 分隔线、描边 |
| `--accent` | `#4C8DFF` | 主强调、置顶标记、焦点环 |
| `--accent-hover` | `#6AA3FF` | 强调悬停 |
| `--accent-soft` | `rgba(76, 141, 255, 0.16)` | 选中/高亮底色 |
| `--text` | `#E8EEF7` | 主文字 |
| `--text-secondary` | `#9FB3CC` | 时间、次要说明 |
| `--text-muted` | `#6E82A0` | 占位符、禁用 |
| `--danger` | `#E05C5C` | 删除操作 |
| `--danger-soft` | `rgba(224, 92, 92, 0.16)` | 删除悬停底色 |
| `--success` | `#3FA67A` | 成功状态 |
| `--toast-bg` | `#17335C` | 提示条底色 |
| `--shadow` | `rgba(0, 0, 0, 0.35)` | 窗口阴影（由系统合成，CSS 备用） |

对比度要求：主文字与背景对比度 ≥ 7:1，次要文字 ≥ 4.5:1。置顶内容仅通过颜色无法区分时，必须有图标辅助（见卡片规范）。

## 3. 字体

```css
font-family: "Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif;
```

| 场景 | 字号/行高 | 字重 |
|---|---|---|
| 卡片正文/预览 | 13px / 1.5 | 400 |
| 时间、计数 | 11px / 1.3 | 400 |
| 搜索框 | 14px / 1.4 | 400 |
| 分区标题（置顶/结果） | 12px / 1.2 | 500 |
| 设置页标题 | 15px / 1.4 | 500 |
| 设置行标签 | 13px / 1.4 | 400 |
| 按钮文字 | 13px / 1.2 | 500 |

英文与数字使用同字体（Segoe UI 回退），不使用斜体。

## 4. 尺寸与间距

- 基础间距单位 **8px**；常用：4 / 8 / 12 / 16 / 24。
- 窗口：默认 **420×620**；最小 **360×500**；禁用最大化；初始高度不超过屏幕工作区（含任务栏之外区域）的 90%。
- 标题栏高度：48px；内容区左右内边距：12px。
- 卡片内边距：12px；卡片间距：8px；卡片圆角：10px。
- 按钮圆角：8px；搜索框圆角：8px；提示条圆角：8px。
- 滚动条：宽 6px；滑块 `#2A4A78`，悬停 `#36619B`，轨道透明；仅内容区出现。

## 5. 布局结构

```
┌────────────────────────────────────────────┐
│ [🔍 搜索历史记录…]            [⚙] [×]      │ 48px 标题栏（可拖动）
├────────────────────────────────────────────┤
│  📌 置顶                                    │ 分区标题（有置顶时显示）
│  ┌──────────────────────────────────────┐  │
│  │ 卡片（置顶）                          │  │
│  └──────────────────────────────────────┘  │
│  全部记录 / 搜索结果                        │ 分区标题（搜索时显示"搜索结果"）
│  ┌──────────────────────────────────────┐  │
│  │ 卡片                                  │  │
│  ├──────────────────────────────────────┤  │
│  │ 卡片                                  │  │
│  └──────────────────────────────────────┘  │
│  …滚动自动加载更多                          │
└────────────────────────────────────────────┘
```

- 标题栏整体为拖动区（`-webkit-app-region: drag`）；搜索框、设置、关闭按钮及所有可点击元素设置 `no-drag`。
- 搜索框占据左侧弹性空间；设置（齿轮）与关闭（×）为 28×28 图标按钮。
- 列表为唯一滚动区域。
- 设置页为窗口内整页覆盖视图：顶部返回箭头 + 标题「设置」，底部显示版本号。

## 6. 组件规范

### 6.1 搜索框

- 占位符：「搜索历史记录…」，颜色 `--text-muted`。
- 左侧放大镜图标 14px，颜色 `--text-muted`。
- 有内容时右侧出现清空按钮（×），点击清空并保持焦点。
- 聚焦：1px `--accent` 描边 + `--accent-soft` 外发光（不改变布局尺寸）。
- 输入防抖 200ms；中文输入法 composition 期间不触发搜索，结束后触发。

### 6.2 卡片

结构：内容区 + 元信息行。

- **文字内容**：最多 5 行，`white-space: pre-wrap`，`word-break: break-word`（长链接/长单词换行），超出以省略号截断（`-webkit-line-clamp: 5`）。正文颜色 `--text`。
- **图片内容**：缩略图最大宽度 100%，最大高度 120px，等比缩放（`object-fit: contain`），背景 `--bg`，圆角 6px；加载中显示同尺寸占位（`--bg-elevated` 闪烁 200ms）。
- **元信息行**：高度 24px；左侧时间（11px，`--text-secondary`），右侧操作按钮（悬停或卡片获得焦点时显示）。
- **操作按钮**：置顶（图钉）、删除（垃圾桶），24×24，图标 16px；悬停背景 `--bg-hover`；删除悬停背景 `--danger-soft`、图标 `--danger`。
- **悬停态**：卡片背景 `--bg-hover`；按钮 120ms 淡入。
- **置顶标识**：卡片左侧 2px `--accent` 竖条 + 元信息行常显图钉图标（`--accent`），不依赖颜色单一维度。
- **按下态**：背景 `--bg-active`。
- **禁用/加载**：不做骨架卡片，仅按钮 loading 时降低透明度。

### 6.3 分区标题

- 12px、500 字重、`--text-secondary`、字距 0.5px。
- 置顶分区带图钉图标（`--accent`，12px）。
- 无置顶时不显示置顶分区标题。
- 搜索时普通分区标题改为「搜索结果」。

### 6.4 空状态

- 居中显示：剪贴板线框图标（48px，`--text-muted`）。
- 文案：
  - 无记录：「还没有记录，复制点什么试试」
  - 搜索无结果：「没有找到相关内容」
- 文案 13px、`--text-secondary`；图标与文案间距 12px。

### 6.5 提示条（Toast）

- 位置：窗口底部居中，距底 16px。
- 规格：`--toast-bg` 背景、1px `--border`、圆角 8px、内边距 8px 16px、12px 文字 `--text`、阴影。
- 动画：淡入/淡出 150ms，显示 1.5s。
- 文案：「已复制」「复制失败，请重试」「已置顶」「已取消置顶」等。
- 错误提示使用 `--danger` 图标 + 文案；技术细节只在日志中。

### 6.6 顶部错误条

- 数据保存失败等严重问题时，在标题栏下方显示内联错误条：`--danger-soft` 背景、`--danger` 文字、左侧警告图标、右侧关闭按钮。
- 文案示例：「数据保存失败，请检查磁盘空间或文件夹权限」。

### 6.7 按钮与表单控件（设置页）

- 图标按钮：28×28，悬停 `--bg-hover`，焦点环 2px `--accent`。
- 文字按钮：无边框，13px；危险操作（清空历史）使用 `--danger`，悬停 `--danger-soft` 背景。
- 下拉框：深色背景 `--bg-elevated`、1px `--border`、圆角 8px、高度 32px；展开后选项悬停 `--bg-hover`。
- 数字输入框：同下拉框规格；范围 1–30，非法值阻止提交并显示提示。
- 开关：36×20，圆角 10px；关闭 `--border`，开启 `--accent`；滑块白色 16px；点击切换即时生效。
- 设置行：标签左对齐、控件右对齐；行高 48px；行间用 1px `--border` 分隔。

### 6.8 系统确认弹窗

使用 Electron 原生 `dialog.showMessageBox`（中文），由主进程发起：

| 场景 | 标题 | 正文 | 按钮 |
|---|---|---|---|
| 删除置顶内容 | 删除置顶内容 | 这条内容已置顶，删除后无法恢复。确定删除吗？ | 取消 / 删除（默认取消） |
| 缩短保存天数 | 缩短保存天数 | 保存天数改为 N 天后，将清理 X 条过期记录（置顶内容不受影响）。 | 取消 / 继续（默认取消） |
| 清空历史 | 清空历史 | 将清空 X 条未置顶记录，置顶内容会保留。此操作无法撤销。 | 取消 / 清空（默认取消） |

危险按钮使用「删除」「清空」明确动词，不使用「确定」。

## 7. 时间显示规则

纯函数实现（`time.js`），每 30 秒刷新一次时间文本：

| 条件 | 显示 |
|---|---|
| 距今 < 60 秒 | 刚刚 |
| 距今 < 60 分钟 | N 分钟前 |
| 与当前同一天 | 今天 HH:mm |
| 与当前相差一天 | 昨天 HH:mm |
| 同一年 | M月D日 HH:mm |
| 其他 | YYYY年M月D日 HH:mm |

- 24 小时制，补零到两位分钟（如 09:05）。
- 使用本地时区；以 `createdAt` 为准。

## 8. 交互规则

| 操作 | 行为 |
|---|---|
| 点击卡片内容区 | 复制回剪贴板；toast「已复制」；不改变排序与时间 |
| 点击置顶按钮 | 切换置顶；即时生效；toast 反馈 |
| 点击删除按钮 | 非置顶直接删除；置顶弹系统确认框 |
| 搜索输入 | 200ms 防抖过滤；置顶区参与；图片隐藏；分页重置 |
| 搜索框内有内容按 Esc | 清空搜索（不隐藏窗口） |
| 搜索框为空按 Esc | 隐藏窗口到托盘 |
| Ctrl+F | 若在设置页先返回列表，再聚焦搜索框 |
| 滚动到底 | 自动加载下一页（每页 100 条），加载中显示小号 spinner |
| 点击托盘图标 | 显示/隐藏切换；显示时聚焦窗口 |
| 关闭按钮 / Alt+F4 | 隐藏到托盘（不退出） |
| 托盘菜单 | 打开窗口 / 退出 |

其他：

- 列表刷新时尽量保留滚动位置；置顶/删除导致条目移动属预期。
- 置顶按钮立即改变分区，不等待动画。
- 所有可交互元素提供键盘焦点可见样式（2px `--accent` 焦点环）。
- 图标按钮必须有中文 `aria-label` 与 `title`（如「置顶」「删除」「设置」「关闭」）。

## 9. 图标与托盘

- 应用图标：圆角方形深蓝底（`#0B1E36`），白色剪贴板主体，`--accent` 高光线；提供 256/128/64/48/32/16 多尺寸 `.ico`。
- 托盘图标：单色浅色版本（浅色剪贴板轮廓），保证深色任务栏可见；16×16 与 32×32 PNG（按 DPI 选择）。
- 不使用文字徽标；不使用复杂渐变。

## 10. 可访问性与兼容

- 支持键盘 Tab 顺序：搜索框 → 设置 → 关闭 → 卡片操作按钮。
- 焦点状态不使用纯颜色区分（配合描边）。
- DPI 100% / 125% / 150% / 200% 下布局不溢出、文字不截断异常；窗口高度受屏幕工作区限制。
- 1366×768 等小屏可用（最小尺寸 360×500 保证列表可用）。

## 11. 中文文案规范

- 简洁、动词开头、使用中文标点；不使用感叹号堆叠。
- 统一用「记录」称呼历史条目；「置顶」「取消置顶」「删除」「搜索历史记录」。
- 错误提示说明「发生了什么」+「可以怎么办」，不暴露英文报错。
