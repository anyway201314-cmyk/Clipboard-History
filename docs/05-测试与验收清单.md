## 0. 标记与级别

- 结果标记：⬜ 未测 / ✅ 通过 / ❌ 失败 / ➖ 不适用
- 问题级别：
  - **P0**：数据丢失、数据损坏、无法启动、无法记录
  - **P1**：核心功能不可用（复制、置顶、删除、搜索、清理、托盘）
  - **P2**：体验问题（样式、文案、性能可接受范围内的卡顿）
