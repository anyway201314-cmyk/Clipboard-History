## 1. 产品概述

「历史剪贴板」是一个运行在 Windows 电脑上的个人剪贴板历史工具。

- 常驻后台，自动记录用户复制过的**文字**和**图片**；
- 打开后以时间倒序的卡片列表展示历史，支持置顶、删除、搜索；
- 点击卡片可将内容复制回剪贴板，供再次粘贴；
- 按保存天数自动清理旧记录（置顶内容永久保留）；
- 界面简洁直观，深蓝色主题，全中文；
- 免安装绿色版，双击运行；数据只保存在本机。

## 2. 目标用户与场景

- 目标用户：非程序员个人用户（单人使用，仅本机）。
- 典型场景：找回几分钟或几小时前复制的文字；重新粘贴之前复制过的截图；把常用内容置顶随手取用；搜索历史中的关键词。

## 3. 功能需求

### 3.1 记录范围

| 编号 | 需求 |
|---|---|
| R1.1 | 自动记录剪贴板中的纯文字（网页、聊天、文档等来源） |
| R1.2 | 自动记录剪贴板中的图片（截图、图片复制等来源） |
| R1.3 | 不记录文件（在资源管理器中复制文件） |
| R1.4 | 相同内容再次复制（如 A→B→A）时，不新增卡片，更新原卡片时间并排到最前；判断重复时文字忽略换行符差异与首尾空白，图片按像素内容判重；若为置顶内容，移到置顶区最前 |
| R1.5 | 软件启动时，剪贴板中已有的内容只作为基线，不主动记录（避免写入启动前的敏感内容） |
| R1.6 | 点击卡片复制回剪贴板时，同样更新该条目时间并移到列表最前；置顶内容移到置顶区最前（自写抑制仅用于避免重复采集） |
| R1.7 | 空白文字不记录；单条文字上限 20 万字符、单张图片上限 20MB，超限跳过并提示 |
| R1.8 | 最多保留 5000 条；超出时只裁剪最旧的非置顶条目 |
| R1.9 | 界面中每个卡片的内容都是唯一的；启动时自动合并历史遗留的重复条目（文字按归一化内容、图片按像素内容） |

### 3.2 历史列表

| 编号 | 需求 |
|---|---|
| R2.1 | 打开窗口后，以卡片列表展示历史，按复制时间降序（最新在最上） |
| R2.2 | 置顶区固定在列表顶部，按置顶时间倒序；普通区按复制时间倒序 |
| R2.3 | 文字卡片显示最多 5 行预览，超出省略；图片卡片显示缩略图 |
| R2.4 | 卡片显示相对时间：刚刚 / N 分钟前 / 今天 HH:mm / 昨天 HH:mm / M月D日 HH:mm / YYYY年M月D日 HH:mm |
| R2.5 | 列表分页加载（每页 100 条，滚动到底自动加载） |
| R2.6 | 无记录时显示空状态提示 |

### 3.3 卡片操作

| 编号 | 需求 |
|---|---|
| R3.1 | 点击卡片：复制内容回剪贴板，显示短暂提示「已复制」 |
| R3.2 | 置顶 / 取消置顶（即时生效，无需确认） |
| R3.3 | 删除：普通记录直接删除；置顶记录删除前二次确认 |
| R3.4 | 鼠标悬停时显示置顶、删除按钮；点击按钮不触发复制 |

### 3.4 搜索

| 编号 | 需求 |
|---|---|
| R4.1 | 顶部搜索默认收起，仅左上角显示搜索图标；点击图标展开输入框，输入即时过滤（防抖 150–250ms，兼容中文输入法） |
| R4.2 | 搜索全文内容（不限于 5 行预览）；中文子串匹配；英文不区分大小写 |
| R4.3 | 置顶区同样参与过滤；搜索时隐藏图片卡片 |
| R4.4 | 无结果时显示提示；清空搜索恢复完整列表 |

### 3.5 保存与清理

| 编号 | 需求 |
|---|---|
| R5.1 | 设置中可选保存天数：3 / 5 / 7 天，或自定义 1–30 天；默认 7 天 |
| R5.2 | 保存期按 24 小时 × 天数计算 |
| R5.3 | 软件运行期间每小时清理一次；启动时补清理一次；修改设置后立即清理一次 |
| R5.4 | 过期清理只删除未置顶记录；置顶内容永久保留，除非手动取消置顶或删除 |
| R5.5 | 缩短保存天数前先向用户确认将要清理的记录数 |
| R5.6 | 清理记录时同步删除对应的图片与缩略图文件 |

| R6.3 | 单实例：重复启动时聚焦已存在的窗口 |
| R6.4 | 不提供全局快捷键 |
| R6.5 | 设置中提供「开机自动启动」开关，默认关闭；开启后隐藏到托盘启动 |
| R6.6 | 移动程序文件夹后，需手动启动一次以重新注册自启路径 |

### 3.8 界面

| 编号 | 需求 |
|---|---|
| R8.1 | 半透明白色背景（Windows 11 亚克力材质）、黑色文字、简洁卡片风格、全中文界面 |
| R8.2 | 默认窗口 420×620（可缩放，最小 360×500，禁用最大化，按屏幕工作区限高） |

### 3.9 数据与隐私

| 编号 | 需求 |
|---|---|
| R9.1 | 数据只保存在本机，软件不联网、无账号、不上传 |
| R9.2 | 绿色便携：数据存放在程序文件夹内，整体拷贝即可迁移 |
| R9.3 | 数据为明文（JSON + 图片文件），同一 Windows 账户下的其他程序可读取；不做加密 |
| R9.4 | 程序日志不记录剪贴板正文 |

## 4. 验收口径

- 以《05-测试与验收清单》逐项勾选为准，P0/P1 问题必须清零。
- 用户实际完成核心操作（打开、复制使用、置顶、删除、搜索、修改保存天数、清空、打开数据文件夹、退出）即为功能验收通过。

## 5. 非目标（本版本不做）

- 记录文件、保留富文本格式
- 全局快捷键
- 安装器、自动更新
- 云同步、多设备
- 敏感内容自动忽略、数据加密
- 导出/备份功能（用户可自行拷贝 `data` 文件夹）
- 多语言界面

## 6. 已知限制（向用户说明）

1. 轮询采集存在漏记窗口：连续复制内容的间隔小于约 600ms（文字）/ 1500ms（图片）时可能漏记。
2. 剪贴板内容没有变化时，再次按复制无法被感知（不会更新时间）。
3. 极少数软件（密码输入框、部分安全软件）会阻止内容被记录。
4. 图片按原样保存，占用空间取决于使用量，依赖保存期自动清理。
